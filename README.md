# אילן היוחסין שלנו

אתר אילן יוחסין משפחתי: עץ שמתמרכז סביב מי שמחובר, בעברית, בצרפתית ובאנגלית.

## הפעלה במחשב

```bash
npm install        # פעם ראשונה בלבד
npm run dev        # ואז לפתוח http://localhost:5173
```

## ייבוא מ-MyHeritage

1. ב-MyHeritage: עץ משפחה ← ניהול עצים ← ייצוא ל-GEDCOM
2. לשים את קובץ ה-`.ged` בתיקייה הזו
3. להריץ `npm run import:gedcom`

## מבנה

| תיקייה / קובץ | מה יש בו |
|---|---|
| `src/lib/graph.ts` | מי קשור למי (הורים, ילדים, בני זוג, אחים) |
| `src/lib/relation.ts` | חישוב הקרבה בין הצופה לכל אדם |
| `src/lib/i18n.ts` | כל הטקסטים בשלוש השפות, כולל שמות קרבה ותאריך עברי |
| `src/lib/layout.ts` | מיקום הכרטיסים בעץ |
| `src/components/` | מסכי האתר: עץ, כרטיס אדם, טופס, דף ממצאים |
| `scripts/` | ייבוא GEDCOM |

## ⚠️ פרטיות

`*.ged`, `src/data/*.local.json`, `.env.local`
